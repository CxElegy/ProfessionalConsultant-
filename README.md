# Consultant Dojo

プロフェッショナルなコンサルタントを目指すための、毎日のトレーニングサイトです。ビルド不要の静的サイトなので、`index.html` をブラウザで開くか、GitHub Pages で公開すればすぐ使えます。

## 機能
- **ホーム**：今日のメニュー（日替わり）、連続日数、スキル平均、今日の一言
- **学習リソース**：学習は外部の信頼できる学習サイトで行います。6テーマ・32件（グロービス知見録・MBA用語集、Schoo、Coursera、McKinsey / BCG / Bain の公式ケース教材、総務省統計局、gacco、storytelling with data、DIAMOND ハーバード・ビジネス・レビューなど）を案内し、学習済みチェックとメモで進捗を記録
- **自己診断**：8スキル（論点設定・構造化・仮説思考・定量分析・資料作成・コミュニケーション・クライアントマネジメント・プロジェクト推進）を5段階の行動基準で評価し、レーダーチャートで前回と比較
- **思考の型**：各カードに参考リンク（グロービス MBA用語集）付き。MECE、イシューツリー、ピラミッド、空・雨・傘、3C など12の型を「使う場面」「落とし穴」「練習問題」付きで学習
- **ケース練習**：15分タイマー付きで、論点→構造→仮説→検証→結論を書き、模範的な考え方とセルフチェックで振り返り
- **フェルミ推定**：推定値を入力すると桁のずれを判定（「3億」「1.2万」表記にも対応）
- **クイズ**：現場判断を問う10問（解説付き）
- **習慣・振り返り**：プロ習慣のチェックリスト、28日間のヒートマップ、KPT記録、データの書き出し

記録はブラウザの localStorage にのみ保存されます。演習は `js/data.js`、学習リソースのリンク集は `js/resources.js` を編集すれば追加・変更できます。

リンク先の内容・料金・公開状況は各運営元によって変わることがあります（2026年11月時点で掲載を確認）。
