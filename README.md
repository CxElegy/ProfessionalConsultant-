# Daily Card

1日1枚、例を読んで課題を自分で解き、解答例と比べて自己採点する、コンサルタントの基礎トレーニングです。

## 使い方
1. ページを開くと「今日のカード」が1枚出る（論点・仮説／構造化／示唆を出す／数字／資料・伝え方／仕事の進め方 の6テーマを巡回、全30枚）
2. 一言ポイントと「例」（✕→○）を読む
3. 「課題」に自分の回答を書く（ヒントあり）
4. 「解答例と比べる」で解答例・チェックポイントを確認し、◎できた／○だいたい／△もう一度 で自己採点
5. △のカードは3日後に復習として出題。全30枚を解いた後は、期日が来たカードが復習として出てくる

解いたカードは「わたしのカード」に回答つきで貯まります。記録はブラウザの localStorage にのみ保存され、「記録を書き出す」で JSON として保存できます。

## ファイル
- `index.html` / `css/style.css` / `js/app.js` — ページ本体（ビルド不要。`index.html` を開くか GitHub Pages で公開）
- `js/cards.js` — 課題カードの中身（ポイント・例・課題・ヒント・解答例・チェックポイント）。ここを編集すればカードを追加・変更できます

用語の定義は、グロービス経営大学院 MBA用語集の該当ページを参考リンクとして各カードに付けています。
