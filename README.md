# Daily Card

1日1枚、プロのコンサルタントに必要な力を学ぶためのカードです。

学習そのものは外部の信頼できる学習サイト（グロービス知見録・MBA用語集、McKinsey / BCG / Bain の公式ケース教材、総務省統計局、Coursera、Schoo、storytelling with data など）で行います。このサイトは毎日1枚のカードを出し、学んだことを自分の言葉で書き残す場所です。

## 使い方
1. ページを開くと「今日のカード」が1枚届く（テーマを巡回しながら全32枚）
2. リンク先で読む・見る
3. 学んだ要点を自分の言葉で一文に書き、「明日の仕事でどう使うか」を書いて完成させる
4. 完成したカードは「わたしのカード」に貯まり、連続日数と過去28日の記録が表示される

気分に合わなければ「別のカードにする」で差し替えられます。記録はブラウザの localStorage にのみ保存され、「記録を書き出す」で JSON として保存できます。

## ファイル
- `index.html` / `css/style.css` / `js/app.js` — ページ本体（ビルド不要。`index.html` を開くか GitHub Pages で公開）
- `js/resources.js` — カードになる外部学習サイトのリスト。ここを編集すればカードを追加・変更できます

リンク先の内容・料金・公開状況は各運営元によって変わることがあります（2026年11月時点で掲載を確認）。
